## Bổ sung cùng ngày — FX thế trận BỀN (nhánh `feature/stance-persistent-fx` → main @014b4c5)

Yêu cầu chủ dự án: bấm Tấn Công/Phòng Thủ/Đột Kích → FX hiện MÃI tới khi server gỡ hoặc ĐỔI thế
(không tự tắt sau lượt). Cách làm: dùng lại nguyên hạ tầng FX bền — server ghi `ActiveEffect`
`stance_dotkich|tancong|phongthu` (RemainingRounds -1 = UntilRemoved, `DecrementEffects` đã guard)
qua `SideState.SetExclusiveEffect(prefix, fxId)` (độc quyền theo tiền tố: đổi thế → gỡ id cũ, thêm mới)
gọi trong `BattleRunner.StepRound` cho cả 2 phe. Client: bỏ hẳn one-shot (`SendStance` preview +
case `StanceChosen` PlayUnderFoot + cờ `_stancePreviewShown`); `PersistentFxFormat` map `stance_*`
→ 3 field art `stanceDotKichFx/…` sẵn có — server chỉ biết id ngữ nghĩa. TDD 4 test mới
(`StancePersistentFxTests`) — 118/118. Playtest: phongthu giữ nguyên qua 4 hiệp, đổi tancong/dotkich
là fx swap trong snapshot; lưu ý đo trạng thái phải đợi client TIÊU hết hàng đợi event (eventPace)
vì `StateMsg` xếp sau `Batch`.

`eff/formation` bake **Animator** với clip one-shot "lóe rồi tàn" — `EffectVisual.Play` chỉ áp loop
