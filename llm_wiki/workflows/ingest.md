# Ingest Workflow

1. Read `wiki/index.md`.
2. Read the source in `raw/sources/`.
3. Create or update `wiki/sources/<source-slug>.md`.
4. Extract claims, concepts, entities, maps, and open questions.
5. Update `wiki/claims.md` and `wiki/contradictions.md` when needed.
6. Update `wiki/index.md`.
7. Append `wiki/log.md`.
